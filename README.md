## About me

I am a **Software Developer focused on process automation, Full Stack applications, and Applied AI**. I build end-to-end solutions using **Python, JavaScript/TypeScript, React/Next.js, FastAPI, Node.js, PostgreSQL, and Docker**.

My work usually sits at the intersection of software engineering and operational efficiency: internal systems, corporate integrations, document processing, RPA, APIs, dashboards, AI-assisted workflows, and local/private LLM solutions.

In my current role, I work across the complete delivery cycle, from architecture and implementation to deployment, monitoring, maintenance, and infrastructure. This includes large-scale document ingestion, OCR routing, RAG pipelines, SharePoint synchronization, financial automation, Docker environments, and CI/CD.

**Local-first Japanese manga study workspace**

A privacy-oriented reading and language-study application that preserves original manga pages while running OCR and deterministic linguistic analysis locally. The architecture includes a React reader, FastAPI API, PostgreSQL queue, worker processing, Sudachi/JMdict integration, optional Gemini enrichment, Docker Compose, full-stack tests, CI, and security/privacy boundaries.

`React` · `FastAPI` · `PostgreSQL` · `Docker` · `OCR` · `Sudachi` · `JMdict` · `Gemini`
